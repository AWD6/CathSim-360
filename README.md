# CathSim 360

เว็บภาษาไทย React + TypeScript + Vite + React Three Fiber / Three.js สำหรับพัฒนาระบบจำลองดูแลสายสวนปัสสาวะที่บ้าน

## GitHub Pages

โครงการ: https://github.com/AWD6/CathSim-360

URL หลังเผยแพร่สำเร็จ: https://awd6.github.io/CathSim-360/

เปิด Settings → Pages → Build and deployment → Source: **GitHub Actions** ครั้งแรก แล้วดู workflow **Test and publish CathSim 360** ในแท็บ Actions ทุกครั้งที่อัปเดต branch `main` ระบบจะติดตั้ง dependencies จาก lockfile ทดสอบ สร้างเว็บ และเผยแพร่เมื่อผ่านทั้งหมด เริ่มรอบใหม่เองได้จาก Actions → Run workflow

ไม่ต้องใช้ API key หรือ secret เพิ่ม แอปเป็น static website ผลการทดลองอยู่ในเบราว์เซอร์ของแต่ละเครื่อง ไม่มีฐานข้อมูลส่วนกลางหรือการซิงก์รายงานข้ามเครื่อง

Vite ใช้ `base: './'` ให้ไฟล์โหลดได้ใต้ `/CathSim-360/` แพ็กสำหรับ GitHub ไม่รวมข้อมูลผูกกับโฮสต์เดิมใน `.openai/` หรือไฟล์ runtime

## สถานะเนื้อหาทางคลินิก

ยังไม่ได้รับไฟล์ `คู่มือปฏิบัติงานสำหรับพยาบาลในการดูเเลผ.pdf` จากแชตเดิม ไม่มีการสร้างคำแนะนำ ลำดับหัตถการ เกณฑ์ผ่าน หรือคะแนนทางคลินิกเอง ทั้งสองสถานการณ์ปัจจุบันเป็นการทดสอบกลไกซอฟต์แวร์เท่านั้น **ยังไม่ใช่บทเรียนทางคลินิกที่สมบูรณ์ และยังไม่พร้อมใช้ฝึกผู้ป่วยจริง**

ไฟล์ `src/clinical.ts` เตรียมที่เก็บข้อความต้นฉบับ เลขหน้า กลุ่มผู้ใช้ และสถานะตรวจรับ เมื่อได้รับคู่มือ ต้องตรวจบทที่ 4 แยกกิจกรรมพยาบาล/ผู้ดูแล เชื่อมข้อกำหนดจากต้นฉบับเข้ากับ engine และให้ทีมตรวจรับก่อนเปิดการประเมิน ห้ามถือการโต้ตอบ 100% เป็นความสามารถหรือความปลอดภัย

## ใช้งาน

ติดตั้ง Node.js 20.19+ หรือ 22.12+ และ pnpm แล้วรันในโฟลเดอร์นี้:

```sh
pnpm install
pnpm dev
pnpm test
pnpm build
```

เปิด URL จาก Vite ในเบราว์เซอร์ แพ็ก production อยู่ใน `dist/` และใช้ static hosting ได้

## ที่พัฒนาแล้ว

- ฉากบ้าน/ห้องนอน 3D หมุนและซูม ตัวละคร CathGuide แบบ procedural พร้อมแขนเคลื่อนไหว
- ภารกิจตำแหน่งถุง: คลิกเลือกและปรับระดับ ถุงกับสายเคลื่อนไหวตามกัน ปุ่มและ slider สำหรับคีย์บอร์ด/มือถือ
- ภารกิจเทของเหลว: ภาชนะเคลื่อนที่ วาล์วเปิดปิด การไหลและระดับลดลง ปริมาณในภาชนะเพิ่มเมื่ออยู่ใต้จุดไหล (ไม่มีหน่วยหรือค่าเกณฑ์ทางคลินิก)
- CathLearn สาธิตกลไกตามเวลา, CathPractice มีคำอธิบายการใช้งาน, CathChallenge ทดลองกลไกโดยไม่มีคำใบ้ (การประเมินคลินิกถูกปิด)
- CathReport บันทึกความครอบคลุมปุ่ม จำนวนการโต้ตอบ เวลา และโหมดใน localStorage ลบและส่งออก JSON ได้ ไม่ใช้บัญชี ไม่มีข้อมูลระบุตัวผู้ป่วยหรือ analytics
- เสียงต้อนรับไทยใช้ Web Speech API ขึ้นกับเสียงที่อุปกรณ์ติดตั้ง ไม่ใช่เสียงสอนหัตถการ

## สถาปัตยกรรมและ XR

`engine.ts` เป็น pure transition API ใช้ร่วมกันได้ทั้งปุ่ม เมาส์ touch หรือ XR controller ในอนาคต `Scene.tsx` แยก presentation และเปิด `gl.xr.enabled` ไว้ ยังไม่มี session entry/controller bindings/locomotion และ **ยังไม่ได้ทดสอบหรือรองรับการใช้งานด้วยแว่น VR จริง** การใช้งาน XR ภายหลังต้องมี HTTPS และการทดสอบอุปกรณ์

## ข้อจำกัด

โมเดล 3D ใช้ primitive geometry เพื่อทดสอบปฏิสัมพันธ์ ไม่ใช่แบบจำลองกายวิภาคหรืออุปกรณ์ที่ผ่าน validation ไม่มี backend/การซิงก์ข้ามเครื่อง/ระบบรายงานพยาบาลส่วนกลาง ข้อมูล localStorage ถูกล้างได้จากเบราว์เซอร์ ฟอนต์ Google เป็นทรัพยากรภายนอก มี fallback เป็นฟอนต์ในเครื่อง

เทคนิคอ้างอิง: [R3F Canvas](https://r3f.docs.pmnd.rs/api/canvas), [R3F Events](https://r3f.docs.pmnd.rs/api/events)
