# CathSim 360

## v0.4 — Interactive care studio

สามโหมด CathLearn / CathPractice / CathChallenge พร้อมห้อง 3D หุ่นผู้ป่วย และหุ่นฝึกชาย–หญิง หมุน ซูม เลื่อนมุมมอง และแตะอุปกรณ์ได้ ปรับระดับถุงเทียบเอวและกระเพาะปัสสาวะ วางภาชนะ เปิด–ปิดก๊อก ดูน้ำลด เช็ดก๊อก ติดเทปหน้าขา เปลี่ยนถุง และฟอก/ล้าง/ซับ

พยาบาลแคธใช้ภาพเวกเตอร์เคลื่อนไหว กระพริบตา ขยับปาก และโบกมือ พร้อมตัวละครในฉาก เสียงหญิงไทย 38 ไฟล์ปรับ -10% / +8Hz และพักระหว่างประโยค 240ms ดนตรีสังเคราะห์ต้นฉบับลดระดับขณะพูด เสียงชื่นชมเมื่อกดทำแล้ว เบราว์เซอร์อาจต้องให้ผู้ใช้แตะครั้งแรกเพื่อเปิดเสียง

รายงานเฉพาะ admin ทั้งหน้าเว็บและบริการ บัญชี patient/caregiver บันทึกความคืบหน้าของรหัสตนเองได้ แต่ดูรายงานไม่ได้ StepEvents เพิ่ม mode และ actions แยกจากการกดทำแล้วและดูผ่าน ส่งออก JSON/CSV และยืนยันก่อนลบประวัติ ไม่มีการอนุมานคะแนนทักษะจริง

ข้อความที่เจ้าของโครงการระบุใช้ชื่อโรงพยาบาลมหาราชนครเชียงใหม่ ดูรายละเอียดแหล่งอ้างอิงและขอบเขตการยืนยันใน docs/EVIDENCE.md

รายละเอียดต่อไปนี้เป็นประวัติรุ่นก่อนหน้า

## อัปเดต v0.3 — ดูและทำไปพร้อมพยาบาลแคธ

หน้าใช้งานหลักเปลี่ยนจากคำถามเลือกตอบเป็น 10 หัวข้อสาธิตพร้อมภาพ 3D รายขั้น ได้แก่ ล้างมือ จัดถุง จัดสาย ยึดสาย เท/เช็ดก๊อก เปลี่ยนถุง ความสะอาดอวัยวะเพศ น้ำ/สีปัสสาวะ นัด และอาการผิดปกติ ใช้ปุ่ม “ทำแล้ว” หรือเปิดมือไม่ว่างเพื่อเลื่อนไปหลังเสียงจบอีก 8 วินาที หยุดพักและดูซ้ำได้ การซ่อนแท็บหยุดเสียงและการนับเวลา

เสียงไทยผู้หญิงเป็นไฟล์ MP3 ที่เตรียมไว้ใน `public/media` (th-TH-PremwadeeNeural, อัตราพูด -15%) ไม่ต้องมีเสียงไทยติดตั้งในเครื่อง หน้าแรกพยายามเล่นเสียงต้อนรับ ถ้าเบราว์เซอร์บล็อกเสียงอัตโนมัติ ให้แตะเริ่มฟังหนึ่งครั้ง ไม่มีตัวเลือกเสียงหรือความเร็ว ภาพพยาบาลแคธชุดขาวสร้างใหม่และจัดเก็บเป็น WebP

รายงานใหม่ใช้ `StepEvents` แยก `confirmed` (ผู้ใช้กดทำแล้ว) จาก `auto` (ดูผ่าน) พร้อม topic/step/time ไม่แปลงเป็นคะแนนความถูกต้องหรือผลสังเกตทักษะจริง ข้อมูลคำถามรุ่นก่อนยังคงอยู่ใน `Attempts` และไม่รวมกับสถิติใหม่ บริการตรวจสิทธิ์บัญชีเดิมและใช้ URL เดิม

ภาพสาธิตเป็นภาพจำลองอุปกรณ์และทิศทาง ไม่ได้จำลองกายวิภาคหรืออุปกรณ์ผู้ผลิตทุกรุ่นอย่างละเอียด คำแนะนำเปลี่ยนถุง/ตำแหน่งยึดต้องใช้ร่วมกับอุปกรณ์และวิธีที่ทีมรักษาสอนไว้

## อัปเดต v0.2

หน้าเรียนใหม่มี CathGuide พยาบาลผู้หญิงแบบภาพเคลื่อนไหว, 7 บทเรียนทีละขั้นพร้อมเหตุผล/แหล่งอ้างอิง, คำถามพร้อม feedback, เสียงไทยจากอุปกรณ์ปรับความเร็วได้, เสียงชื่นชมเปิดปิด, CSV ผลรายข้อ, ฉาก 3D เดิม และหน้าเข้าใช้ด้วยรหัส

ข้อมูลวิชาการล่าสุดและแผนหน่วยงาน: `docs/EVIDENCE.md` (ยืนยันจากเจ้าของโครงการ: ทำความสะอาดวันละ 3 ครั้งตามเวลาตื่น ไม่ใช่ทุก 6 ชั่วโมง)

**เปิดบริการบัญชีรหัสและรายงาน Google Sheet แล้ว** ทดสอบบัญชีสาธิตผู้เรียนและผู้ดูแล การแยกสิทธิ์ และส่งข้อมูลผ่านเบราว์เซอร์ ดูวิธีออกบัญชี/ติดตั้งซ้ำที่ `server/SETUP.md` เสียงพยาบาลหญิงแบบเดียวทุกเครื่องยังไม่มีไฟล์เสียงที่บันทึกไว้ ใช้เสียงที่ระบบปฏิบัติการรองรับ ตัวละคร 3D ยังไม่ได้สาธิตการทำความสะอาดเชิงกายวิภาคอย่างละเอียด ผลในเว็บไม่รับรองทักษะจริง

ส่วนคำอธิบายด้านล่างเป็นรายละเอียดของฉากทดลอง v0.1 ซึ่งยังแยกไว้สำหรับฝึกอุปกรณ์

เว็บภาษาไทย React + TypeScript + Vite + React Three Fiber / Three.js สำหรับพัฒนาระบบจำลองดูแลสายสวนปัสสาวะที่บ้าน

## GitHub Pages

โครงการ: https://github.com/AWD6/CathSim-360

URL หลังเผยแพร่สำเร็จ: https://awd6.github.io/CathSim-360/

เปิด Settings → Pages → Build and deployment → Source: **GitHub Actions** ครั้งแรก แล้วดู workflow **Test and publish CathSim 360** ในแท็บ Actions ทุกครั้งที่อัปเดต branch `main` ระบบจะติดตั้ง dependencies จาก lockfile ทดสอบ สร้างเว็บ และเผยแพร่เมื่อผ่านทั้งหมด เริ่มรอบใหม่เองได้จาก Actions → Run workflow

ไม่ต้องใช้ API key หรือ secret เพิ่ม แอปเป็น static website ผลการทดลองอยู่ในเบราว์เซอร์ของแต่ละเครื่อง ไม่มีฐานข้อมูลส่วนกลางหรือการซิงก์รายงานข้ามเครื่อง

Vite ใช้ `base: './'` ให้ไฟล์โหลดได้ใต้ `/CathSim-360/` แพ็กสำหรับ GitHub ไม่รวมข้อมูลผูกกับโฮสต์เดิมใน `.openai/` หรือไฟล์ runtime

## สถานะเนื้อหาทางคลินิก

ยังไม่ได้รับไฟล์ `คู่มือปฏิบัติงานสำหรับพยาบาลในการดูเเลผ.pdf` จากแชตเดิม ไม่มีการสร้างคำแนะนำ ลำดับหัตถการ เกณฑ์ผ่าน หรือคะแนนทางคลินิกเอง ทั้งสองสถานการณ์ปัจจุบันเป็นการทดสอบกลไกซอฟต์แวร์เท่านั้น **ยังไม่ใช่บทเรียนทางคลินิกที่สมบูรณ์ และยังไม่พร้อมใช้ฝึกผู้ป่วยจริง**

ไฟล์ `src/clinical.ts` เตรียมที่เก็บข้อความต้นฉบับ เลขหน้า กลุ่มผู้ใช้ และสถานะตรวจรับ เมื่อได้รับคู่มือ ต้องตรวจบทที่ 4 แยกกิจกรรมพยาบาล/ผู้ดูแล เชื่อมข้อกำหนดจากต้นฉบับเข้ากับ engine และให้ทีมตรวจรับก่อนเปิดการประเมิน ห้ามถือการโต้ตอบ 100% เป็นความสามารถหรือความปลอดภัย

## ใช้งาน

ติดตั้ง Node.js 20.19+ หรือ 22.12+ และ pnpm แล้วรันในโฟลเดอร์นี้:

```sh
pnpm install
pnpm dev
pnpm test
pnpm build
```

เปิด URL จาก Vite ในเบราว์เซอร์ แพ็ก production อยู่ใน `dist/` และใช้ static hosting ได้

## ที่พัฒนาแล้ว

- ฉากบ้าน/ห้องนอน 3D หมุนและซูม ตัวละคร CathGuide แบบ procedural พร้อมแขนเคลื่อนไหว
- ภารกิจตำแหน่งถุง: คลิกเลือกและปรับระดับ ถุงกับสายเคลื่อนไหวตามกัน ปุ่มและ slider สำหรับคีย์บอร์ด/มือถือ
- ภารกิจเทของเหลว: ภาชนะเคลื่อนที่ วาล์วเปิดปิด การไหลและระดับลดลง ปริมาณในภาชนะเพิ่มเมื่ออยู่ใต้จุดไหล (ไม่มีหน่วยหรือค่าเกณฑ์ทางคลินิก)
- CathLearn สาธิตกลไกตามเวลา, CathPractice มีคำอธิบายการใช้งาน, CathChallenge ทดลองกลไกโดยไม่มีคำใบ้ (การประเมินคลินิกถูกปิด)
- CathReport บันทึกความครอบคลุมปุ่ม จำนวนการโต้ตอบ เวลา และโหมดใน localStorage ลบและส่งออก JSON ได้ ไม่ใช้บัญชี ไม่มีข้อมูลระบุตัวผู้ป่วยหรือ analytics
- เสียงต้อนรับไทยใช้ Web Speech API ขึ้นกับเสียงที่อุปกรณ์ติดตั้ง ไม่ใช่เสียงสอนหัตถการ

## สถาปัตยกรรมและ XR

`engine.ts` เป็น pure transition API ใช้ร่วมกันได้ทั้งปุ่ม เมาส์ touch หรือ XR controller ในอนาคต `Scene.tsx` แยก presentation และเปิด `gl.xr.enabled` ไว้ ยังไม่มี session entry/controller bindings/locomotion และ **ยังไม่ได้ทดสอบหรือรองรับการใช้งานด้วยแว่น VR จริง** การใช้งาน XR ภายหลังต้องมี HTTPS และการทดสอบอุปกรณ์

## ข้อจำกัด

โมเดล 3D ใช้ primitive geometry เพื่อทดสอบปฏิสัมพันธ์ ไม่ใช่แบบจำลองกายวิภาคหรืออุปกรณ์ที่ผ่าน validation ไม่มี backend/การซิงก์ข้ามเครื่อง/ระบบรายงานพยาบาลส่วนกลาง ข้อมูล localStorage ถูกล้างได้จากเบราว์เซอร์ ฟอนต์ Google เป็นทรัพยากรภายนอก มี fallback เป็นฟอนต์ในเครื่อง
