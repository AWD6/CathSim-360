# เชื่อมบัญชีและ Google Sheets

สถานะ: โค้ดบริการพร้อมติดตั้ง แต่ยังไม่มี Web App URL จึงไม่เปิดปุ่ม login ออนไลน์ ห้ามใส่รหัสเข้าใช้ใน GitHub

1. เปิด Google Sheet ที่สร้างให้ (เจ้าของเท่านั้น ห้ามเผยแพร่ลิงก์ข้อมูลต่อสาธารณะ) → Extensions → Apps Script
2. วาง `Code.gs` แล้วเรียก `setup()` เพื่อบันทึก Sheet ID และตรวจหัวตาราง ต้องให้สิทธิ์ในบัญชี Google ของเจ้าของด้วยตนเอง
3. ออกบัญชีด้วย `issueAccount('CS-ABC123','patient',[])` ใน editor สำหรับผู้เรียน และ `issueAccount('CG-ABC123','caregiver',['CS-ABC123'])` สำหรับผู้ดูแล ทำผ่านฟังก์ชันชั่วคราวที่เรียกแล้วอ่านค่าคืนใน debugger ให้กุญแจแก่ผู้ใช้เป็นการส่วนตัว ไม่ใช้ชื่อ/HN ในรหัส
4. Deploy → New deployment → Web app → Execute as: Me → Who has access: Anyone การเข้าถึงข้อมูลต้องผ่านกุญแจและตรวจสิทธิ์ฝั่งบริการ Sheet ยังต้องเป็น private หากนโยบายองค์กรไม่อนุญาต public web app ให้ใช้ backend องค์กรแทน
5. คัดลอก URL `/exec` ตั้ง GitHub Actions variable ชื่อ `REPORT_API_URL` แล้วให้ workflow ส่งเป็น `VITE_REPORT_API_URL` ตอน build (เตรียมไว้แล้ว) ส่ง URL ให้ตรวจการเชื่อมต่อก่อนใช้ข้อมูลจริง
6. ทดสอบบัญชีผู้เรียน A/B ผู้ดูแลที่ผูก A ต้องอ่าน B ไม่ได้, session หมดอายุ, revoked account, duplicate attempt, CORS บนโดเมน GitHub Pages และมือถือ ก่อนนำใช้จริง

ไม่ใช้ Form สำหรับรายงานที่ต้องมีสิทธิ์อ่าน เพราะลิงก์ Form อย่างเดียวไม่ใช่ระบบบัญชีผู้ใช้ ข้อมูลเป็น pseudonymous ไม่ใช่ anonymous อย่างสมบูรณ์: เก็บตารางเชื่อมรหัสกับตัวบุคคลไว้อีกระบบหนึ่งเท่านั้น เจ้าหน้าที่เป็นผู้ควบคุมสิทธิ์/ความยินยอม/ระยะเวลาเก็บ

Attempts เป็นข้อมูลจาก client จึงเป็นคะแนนการเรียนรู้ที่ยังแก้ไขโดยผู้ใช้ได้ ไม่ใช้ยืนยันสมรรถนะทางคลินิก Observations ให้พยาบาลกรอกหลังสาธิตกลับจริง result = demonstrated / needs-practice, assessor_code ใช้รหัสเจ้าหน้าที่, confirmed_cauti ต้องใช้เกณฑ์วินิจฉัยที่หน่วยงานรับรอง ไม่วินิจฉัยจากกลิ่น/สีหรือตอบผิดในเว็บ

สถิติที่ควรแยก: ครั้งแรกก่อนเรียน vs หลังเรียน vs ติดตาม, คะแนนรายข้อ, เวลาที่ใช้ (ไม่ใช่เกณฑ์ผ่าน), จำนวนครั้งฝึก, อัตราสาธิตจริงได้โดยไม่ช่วย, CAUTI ต่อ 1,000 catheter-days เมื่อมีตัวเศษ/ตัวส่วนที่เจ้าหน้าที่ตรวจครบ ขณะนี้ UI ยังไม่มีแบบบันทึกสาธิตจริงหรือ dashboard อัตราติดเชื้อ
